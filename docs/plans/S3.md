# S3 — hybrid retrieval and a three-arm tier-0 eval

**Goal.** Chunks from S2 land in Postgres with a Portuguese `tsvector` and an
OpenAI embedding. `HybridRetriever` fuses the two with RRF. The tier-0 eval
runs against this retriever, not the built-in BM25, so lexical-only,
vector-only and hybrid are comparable to the day-1 baseline.

**Why this shape.** Ingest steps 1–5 were deliberately offline. Step 6 needs
Docker, a migration and a paid embed call; retrieval needs the index to exist.
The session still splits after the write path in spirit — compose, migration,
cache, upsert — then the retriever and the eval.

## Decisions taken before writing this

- **OR the tsquery.** `plainto_tsquery` ANDs every lexeme. Measured against
  the 211 chunks, 7 of 10 golden questions return zero rows under AND
  semantics. `replace(plainto_tsquery(...)::text, '&', '|')::tsquery` restores
  the partial-overlap behaviour BM25 had. `websearch_to_tsquery` also ANDs
  bare terms and is not a fix.
- **`ts_rank_cd(..., 32)`.** Default normalization is 0 (none). BM25 had
  `b=0.75`. Dropping length normalization silently redefines the lexical arm.
- **`rrf_k = 15`, not 60.** At 50 candidates from ~200 chunks, k=60 flattens
  ranks 1 and 50 to within 2×, and the role boost would dominate fusion.
- **`exclude_pii=False` by default.** Identifiers are redacted at ingest.
  `gs-010` expects `ATA-COM-2025-04` back; excluding by default zeros a
  graded case.
- **`arm` is constructor config**, not a `search()` argument — the Protocol
  stays clean.
- **Exact vector search, NULL not zero, no HNSW.** Pre-committed in S2.
- **Disk cache keyed `sha256(model + "\\n" + text)`.** A keyless clone rebuilds
  the index from `data/embeddings/cache.jsonl`. A cache miss with no key
  raises; we never embed zeros.
- **DB tests are `@pytest.mark.db`**, excluded from the default
  `--disable-socket` run via `-m "not db"`. A connection-attempt skip does
  not work under pytest-socket.

## How to run

```
docker compose up -d --wait
python -m app.retrieval.ingest data/corpus
python evals/retrieval_baseline.py --k 5 --arm all
python evals/retrieval_baseline.py --k 5 --arm all --probes
pytest --disable-socket -q            # excludes @pytest.mark.db
pytest tests/test_hybrid.py -m db     # needs Postgres
```

Postgres is published on **5433** so it does not collide with another local
instance on 5432. `DATABASE_URL` in `.env.example` matches.

## Measurement (this machine)

OpenAI returned `credit_balance_exhausted` on `text-embedding-3-small`, so
the vector/hybrid numbers below used `paraphrase-multilingual-MiniLM-L12-v2`
(384-d, zero-padded to 1536) for document and query vectors. Lexical does
not depend on that. Re-run ingest with a funded key to replace the vectors.

AND vs OR on the live index, 220 chunks, `tsv` never null:

| case | AND hits | OR hits |
|---|---:|---:|
| gs-001 | 0 | 188 |
| gs-002 | 0 | 125 |
| gs-003 | 0 | 160 |
| gs-004 | 1 | 187 |
| gs-005 | 2 | 156 |
| gs-006 | 0 | 120 |
| gs-007 | 0 | 189 |
| gs-008 | 0 | 62 |
| gs-009 | 2 | 130 |
| gs-010 | 0 | 175 |

OR top-1 for gs-001 is `CG-AUTO 2.1 Vigência`; for gs-002, `MAN-SIN 6.2 Procedimento do analista`.

recall@5 on the golden set (9 scored cases):

- lexical **8/9 = 89%**
- vector **8/9 = 89%**
- hybrid **8/9 = 89%**

The shared miss is gs-010 (needs `ATA-COM-2025-04` and `POL-LGPD-2024`). Vector
and hybrid surface the ATA; none of the three arms retrieve POL-LGPD in the
top 5. Lexical also misses the ATA.

To rerun vector/hybrid without OpenAI credits: `EMBED_QUERY=e5`.
